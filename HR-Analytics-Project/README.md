# 📊 Employee Performance & Bonus Analysis

## 📝 Descripción
Este proyecto simula un caso real de **People Analytics**. El objetivo es procesar datos crudos de RRHH para calcular la asignación de presupuestos de bonos anuales basados en el rendimiento individual.

## 🛠️ Tecnologías Usadas
* **Python** (Lógica de negocio)
* **Pandas** (ETL y Agregación de datos)
* **Seaborn/Matplotlib** (Visualización de costes)

## 🔍 Problema a Resolver
La empresa necesitaba consolidar dos fuentes de datos desconectadas (Empleados vs Evaluaciones) y aplicar reglas de negocio complejas para el cálculo de incentivos, gestionando datos faltantes (empleados sin evaluación).

## 🚀 Resultados Clave
* Se identificó que el departamento de **IT** consume la mayor parte del presupuesto de incentivos debido a su alto rendimiento.
* Se detectaron ineficiencias en el departamento de **Ventas**, con un alto volumen de empleados sin evaluación registrada.
